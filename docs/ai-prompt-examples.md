# AI 整形（NDG-73）の system_prompt サンプル

NudgeFlow の AI 整形機能は、依頼者が書いた「要件メモ」を AI に渡して、
受信者向けに整えられた `{title, body}` を返してもらう構成です。

provider 別の設定指針:

- **Dify**: プロンプトは Dify の workflow 内で完結させるため、NudgeFlow 側に
  system_prompt を保存しません。`/admin/settings/ai` の system_prompt 欄は
  入力不要（保存しても無視されます）。
- **OpenAI 互換**: NudgeFlow 側の `system_prompt` 列をそのまま system message
  として使います。空のときは下記のビルトインを使用します。

## ビルトイン (OpenAI 互換)

```text
あなたは社内依頼の文書整形アシスタントです。
入力された要件メモから、簡潔な依頼タイトルと、受信者が何をすべきか明確にわかる本文を生成してください。

必ず次の JSON 形式で返してください（他のテキストは一切含めない）:
{"title": "...", "body": "..."}

- title: 30 文字以内、何をするかが一目でわかる
- body: 受信者向けに丁寧語で、目的・期限イメージ・成果物を箇条書きまたは短い段落で
```

## カスタマイズ例

### A. 部署文化に合わせて口調を指定

```text
あなたは社内依頼の文書整形アシスタントです。
出力は必ず次の JSON 形式で:
{"title": "...", "body": "..."}

スタイルガイド:
- title は体言止めで 25 文字以内
- body は敬体（ですます）、Markdown 記法可
- 「お忙しいところ恐縮ですが」「ご対応のほどお願いいたします」など
  クッション言葉を入れる
```

### B. テンプレ化（提出系の依頼が多い課向け）

```text
あなたは社内依頼の文書整形アシスタントです。次の JSON 形式で返してください:
{"title": "...", "body": "..."}

body は次のセクションを必ず含めてください:
- ## 依頼概要
- ## 提出方法
- ## 期限の目安
- ## 不明点があれば
```

### C. ローカル LLM (qwen2.5-coder 等) で安定させる

JSON mode をうまく扱えないモデルがある場合、プロンプト末尾に強い指示を追加すると安定します:

```text
（中略）

重要: 出力は単一の JSON オブジェクトのみ。前後に説明、Markdown コードフェンス、
コメントを一切含めないこと。改行は本文中の自然な箇所のみ。
```

## テスト送信について

`/admin/settings/ai` の「テスト送信」ボタンは、保存済みの設定で固定メモ
**「アンケート回答依頼」** を送信し、`{title, body}` が返ってくるかを
確認します。整形結果が日本語として自然なら疎通 OK です。
