## Task 3: Test workflow

**Files:**
- Create: `.github/workflows/test.yml`

- [ ] **Step 1: Create test.yml**

```bash
mkdir -p .github/workflows
```

Create `.github/workflows/test.yml`:

```yaml
name: Test

on:
  pull_request:
    branches: [main]
  push:
    branches: [main]

concurrency:
  group: test-${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: read

jobs:
  test:
    runs-on: ubuntu-latest
    timeout-minutes: 20

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm

      - name: Enable corepack (pnpm)
        run: corepack enable

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Typecheck
        run: pnpm typecheck

      - name: Run tests (unit + schema + RLS)
        run: pnpm test
```

**Note:** `cache: pnpm` を `actions/setup-node@v4` で指定するためには `corepack enable` を後で実行するか、setup-node の前に手動で pnpm をインストールする必要がある。代わりに pnpm の `setup-pnpm` action を使うアプローチもあるが、corepack の方がリポジトリの `packageManager` フィールドを尊重するので推奨。`cache: pnpm` のみ指定するとキャッシュキーが正しく動かないことがあるので注意。

問題が出たら setup-node の cache を一旦外して、次の代替パターンを検討：

```yaml
      - name: Enable corepack (pnpm)
        run: corepack enable

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: Get pnpm store directory
        run: echo "STORE_PATH=$(pnpm store path --silent)" >> $GITHUB_ENV

      - name: Setup pnpm cache
        uses: actions/cache@v4
        with:
          path: ${{ env.STORE_PATH }}
          key: ${{ runner.os }}-pnpm-store-${{ hashFiles('**/pnpm-lock.yaml') }}
          restore-keys: |
            ${{ runner.os }}-pnpm-store-
```

最初は単純な `cache: pnpm` で試し、動かなければ後者にフォールバックする。

## Task 4: Build & push workflow

**Files:**
- Create: `.github/workflows/build.yml`

- [ ] **Step 1: Create build.yml**

Create `.github/workflows/build.yml`:

```yaml
name: Build & Push

on:
  push:
    branches: [main]
    tags: ['v*']

concurrency:
  group: build-${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: false

permissions:
  contents: read
  packages: write

env:
  REGISTRY: ghcr.io
  IMAGE_NAME: ${{ github.repository }}

jobs:
  build:
    runs-on: ubuntu-latest
    timeout-minutes: 30

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v3

      - name: Log in to GitHub Container Registry
        uses: docker/login-action@v3
        with:
          registry: ${{ env.REGISTRY }}
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Extract metadata
        id: meta
        uses: docker/metadata-action@v5
        with:
          images: ${{ env.REGISTRY }}/${{ env.IMAGE_NAME }}
          tags: |
            type=ref,event=branch
            type=ref,event=tag
            type=sha,prefix=main-,format=short,enable=${{ github.ref == 'refs/heads/main' }}
            type=raw,value=latest,enable=${{ github.ref == 'refs/heads/main' || startsWith(github.ref, 'refs/tags/v') }}
            type=semver,pattern={{version}}
            type=semver,pattern={{major}}.{{minor}}

      - name: Build and push
        uses: docker/build-push-action@v5
        with:
          context: .
          push: true
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
          cache-from: type=gha
          cache-to: type=gha,mode=max
          platforms: linux/amd64
```

注意点：
- `IMAGE_NAME` は `${{ github.repository }}` で自動的に `tetsukame/nudge` になる（リポジトリオーナー名は小文字想定）
- `cache: gha` で GitHub Actions のレイヤーキャッシュを利用、ビルド時間を短縮
- `platforms: linux/amd64` のみ（spec で AMD64 のみと決定済み）
- `permissions: packages: write` で ghcr.io への push 権限を `GITHUB_TOKEN` に付与
